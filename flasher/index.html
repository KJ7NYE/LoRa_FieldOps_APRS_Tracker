Chrome / Edge only · USB cable required

Connect your T114 via USB, then click Install. Updates the firmware only — your saved configuration is preserved.

The board reboots into its bootloader and reconnects as a different USB device, so the first time you'll be asked to pick a serial port twice: once for the tracker, then once for the bootloader.

Chrome / Edge only · USB cable required
This browser doesn't support Web Serial. Use Chrome or Edge to install over USB, or use the UF2 drag-and-drop method below.
Manual install (UF2 drag-and-drop)
  1. Double-tap RESET quickly — the board enters UF2 bootloader mode. A USB drive named T114BOOT (or similar) appears on your computer.
  2. Download Firmware (.uf2) from Download firmware files below.
  3. Drag the downloaded .uf2 file onto the USB drive.
  4. The drive disappears and the board reboots automatically into the new firmware.
